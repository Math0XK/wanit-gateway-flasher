Gateway Flasher

Flashez votre Wanit Gateway en un clic

Branchez le module de flash, choisissez la version, cliquez sur Flasher. Pas d'installation, pas de ligne de commande.

Télécharger pour Windows
Dernière version · Windows 10 et 11 (64 bits) · toutes les versions

Utilisation

  1. Lancez WanitGatewayFlasher.exe. Il n'y a rien à installer.
  2. Branchez le module de flash fourni sur le connecteur Segger du Wanit Gateway, puis sur un port USB du PC. Il est détecté automatiquement.
  3. La dernière version du firmware est sélectionnée par défaut. Vous pouvez en choisir une autre, ou un fichier .bin local.
  4. Cliquez sur Flasher. L'appareil redémarre à la fin et conserve son Wi-Fi et ses réglages.

Windows affiche un avertissement ? C'est normal

L'utilitaire n'est pas signé avec un certificat payant. Windows et votre navigateur se méfient donc d'un programme qu'ils ne connaissent pas encore. Le fichier est publié directement par Wanit sur GitHub et son empreinte est vérifiable sur la page de la release.

Dans le navigateur (Edge ou Chrome)

  1. Si le téléchargement est signalé comme « peu courant », ouvrez le menu … à côté du fichier.
  2. Choisissez Conserver, puis Afficher plus et Conserver quand même.

Au premier lancement (« Windows a protégé votre ordinateur »)

  1. Cliquez sur Informations complémentaires.
  2. Vérifiez que le fichier s'appelle bien WanitGatewayFlasher.exe, puis cliquez sur Exécuter quand même.

Ces avertissements n'apparaissent qu'une fois. Par la suite, l'utilitaire se met à jour lui-même.

Besoin d'aide ?

Si le flash échoue, le message affiché indique quoi faire. Le plus souvent, le connecteur du module est mal enfoncé ou à l'envers sur le connecteur Segger de la carte : rebranchez-le, puis relancez.

Pour le support, ouvrez le Journal dans l'utilitaire, cliquez sur Copier et joignez-le à votre demande. Les binaires du firmware et leur documentation sont sur wanit-gateway-releases.
